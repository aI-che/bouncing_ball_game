# Bouncing Ball Game

A small 2D physics game made with **Python + Pygame**: a ball that jumps under gravity, wraps around the screen edges, and teleports between two portals.

## Features

- Gravity and jumping
- Screen wrap: leave one side and come back on the other
- Two linked portals that teleport the ball and reverse its direction

## Controls

| Key | Action |
| --- | --- |
| `A` / `D` | Move left / right |
| `Space` | Jump |

## Run

```bash
pip install pygame
python main.py
```
